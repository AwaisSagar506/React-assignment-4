# Bus Booking Form & Live Ticket Preview

React practice interface with controlled passenger and destination inputs, a meal option and a live ticket preview.

**Stack:** React, JavaScript, Bootstrap

## What it demonstrates

- Controlled passenger-name and destination inputs using React state.
- Optional VIP meal checkbox.
- Ticket preview updates immediately as inputs change.
- Confirm button stays disabled while the passenger name is empty.

## Run locally

```bash
git clone https://github.com/AwaisSagar506/React-assignment-4.git
cd React-assignment-4
npm ci
npm start
```

Build with `npm run build`. This is an educational UI inspired by a bus-booking flow. It does not submit reservations, persist tickets or connect to a transport operator.
